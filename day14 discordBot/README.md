# discordBot

A powerful Discord bot built with [Discord.js](https://discord.js.org/) and powered by Google's new `@google/genai` SDK. This bot integrates Google's Gemini 2.5 Flash model to provide intelligent, concise conversational responses and includes built-in utility functions for generating images using the Gemini 2.5 Flash Image model.

## ✨ Features

- **Conversational AI**: Automatically replies to user messages using the `gemini-2.5-flash` model.
- **Concise Responses**: Configured with system instructions to keep answers to a maximum of 5 lines for better chat readability.
- **Modern Stack**: Built with Discord.js v14 and the latest official Google GenAI SDK.

## 📋 Prerequisites

Before you begin, ensure you have met the following requirements:
* **Node.js**: Make sure you have Node.js installed (v16.14.0 or higher is required for Discord.js v14).
* **Discord Bot Token**: You need to create an application and a bot in the [Discord Developer Portal](https://discord.com/developers/applications). Ensure you enable the **Message Content Intent** in the bot settings.
* **Gemini API Key**: Get a free API key from [Google AI Studio](https://aistudio.google.com/).
